## 📌 Deskripsi Tugas
Program ini adalah bentuk implementasi **HTML5, Inline CSS, dan Vanilla JavaScript Event Handling** untuk mengelola Form Tambah Data Mahasiswa secara interaktif dan dinamis.

---

## 🚀 8 Fitur & Kriteria Interaktif
Aplikasi ini sudah memenuhi 8 kriteria interaktivitas yang diwajibkan:

1. **Hover Tombol Simpan:** Warna tombol berubah menjadi biru (`#2980b9`) dan sedikit membesar (`scale(1.02)`) saat kursor berada di atas tombol.
2. **Focus Input Field:** Border berubah menjadi biru (`#3498db`) disertai efek *glow* kuning saat elemen input/select sedang difokuskan.
3. **Validasi Form:** Field NIM, Nama Lengkap, dan Mata Kuliah wajib diisi sebelum data dapat disimpan.
4. **Border Validasi Dinamis:** Border berubah menjadi **merah** jika input kosong/invalid dan menjadi **hijau** saat sudah terisi secara benar.
5. **Alert & Output Data:** Menampilkan pop-up `alert()` serta memunculkan blok area output data mahasiswa setelah tombol simpan diklik.
6. **Efek Mengisi Nama:** Background field Nama Lengkap otomatis berubah menjadi warna **biru muda** (`#eef9ff`) saat mulai diketik.
7. **Efek Memilih Mata Kuliah:** Background dropdown Mata Kuliah otomatis berubah menjadi warna **hijau muda** (`#e8f8f5`) setelah opsi dipilih.
8. **Reset Form:** Seluruh isian form dan *styling* background/border otomatis kembali ke keadaan semula setelah data berhasil disimpan.
